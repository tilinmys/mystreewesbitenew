## After saving: compress

From the project root:

```bash
node -e "const sharp=require('sharp'),fs=require('fs'),p='public/images/about';(async()=>{for(const f of fs.readdirSync(p).filter(f=>f.endsWith('.webp'))){const s=fs.readFileSync(p+'/'+f);if(s.length<300000)continue;const o=await sharp(s).webp({quality:82,effort:6}).toBuffer();fs.writeFileSync(p+'/'+f,o);console.log(f,(s.length/1024|0)+'KB ->',(o.length/1024|0)+'KB');}})()"
```

Reading the file into a buffer first matters on Windows: sharp keeps a handle on
a path it opened, and overwriting it in place fails with `UNKNOWN: open`.
